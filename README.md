Cabaicast merupakan sebuah aplikasi berbasis web yang dikembangkan untuk meramalkan harga cabai rawit merah di wilayah Provinsi Jawa Barat. Aplikasi ini memanfaatkan pendekatan Attention Mechanism yang diintegrasikan ke dalam arsitektur Long Short-Term Memory (LSTM), guna meningkatkan kapabilitas model dalam menangkap pola-pola temporal yang kompleks pada data deret waktu harga komoditas. Implementasi sistem dilakukan menggunakan bahasa pemrograman Python dengan dukungan framework Flask sebagai server-side web framework. Antarmuka pengguna dirancang menggunakan HTML, CSS, dan JavaScript, serta diperkuat dengan framework Bootstrap untuk memastikan tampilan yang responsif dan user-friendly.
